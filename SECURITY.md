# Security policy

django-maker-checker enforces controls (segregation of duties, approval before a change is applied), so a way to
bypass them is a security issue even when no data leaks.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on https://github.com/joemash/django-maker-checker.
Do not open a public issue.

Include what is affected, how to reproduce it, and the impact you see. You can expect an acknowledgement within a few
days and a fix or mitigation plan once the report is confirmed. Reporters are credited in the release notes unless
they prefer otherwise.

## Supported versions

Security fixes are made for the latest minor release.
