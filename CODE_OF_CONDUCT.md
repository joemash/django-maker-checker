# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment and
personal attacks are not tolerated.

To report unacceptable behaviour, contact the maintainer privately through the email address on their GitHub profile.
Reports are handled confidentially.
